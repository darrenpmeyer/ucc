# Character map provenance

The checked-in `printable.csv` is generated by `extract_printable.py` from a
local `ucd.all.flat.xml`. The XML identifies itself as **Unicode 18.0.0** and
contains a 2026 Unicode copyright notice. The original download URL and date
were not recorded; version identification alone does not establish whether
this input was a final or prerelease snapshot. These hashes identify the exact
input and output used by this release:

| File | SHA-256 |
| --- | --- |
| `ucd.all.flat.xml` | `31b0125e3bb536238e064b52ff54672608f82953308ef5f365589824363c64b7` |
| `printable.csv` | `867ee5a69cb768ce93431916c33ba13b95d2b29918b7321a27a63ba4979d8e8c` |

Reproduce with Python 3 (standard library only):

```sh
python3 extract_printable.py ucd.all.flat.xml printable.csv
sha256sum ucd.all.flat.xml printable.csv
```

The extractor keeps Unicode general categories L, M, N, P, and S, plus
U+0020 SPACE. It expands algorithmic names and ranges and preserves name aliases.
The CSV has columns `na`, `cp`, `na1`, and `aliases` and 172,620 data records.
The large XML is not distributed in release packages; ordinary builds use the
checked-in CSV and require no Unicode downloads.

Upstream: https://www.unicode.org/ucd/

For future data updates, download a versioned archive, for example
https://www.unicode.org/Public/18.0.0/ucdxml/ucd.all.flat.zip,
and record the archive URL, retrieval date, archive and extracted-file hashes,
and output hash. Do not use the moving `latest` URL for a release input.
The versioned URL above is a reference, not a verified origin of our local XML.
